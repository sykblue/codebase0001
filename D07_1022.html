비유: 같은 심부름, 다른 심부름꾼

어제는 브라우저가 API에 주문했고, 오늘은 파이썬이 주문해요. 어제 HTML의 fetch가 오늘 파이썬에선 requests예요. 그리고 오늘은 키 없는 분식집이 아니라 키가 필요한 오픈API(OpenWeather, ExchangeRate-API)예요.

왜 파이썬으로?

비유: 심부름을 한 번에 몰아서

① 여러 API를 차례로 (날씨 보고 → 환율 보고 → 공휴일 보고) ② 결과를 파일로 저장하거나 매일 자동 실행 ③ 내 컴퓨터에서만 돌아서 회원 카드(키)를 숨길 수 있어요. 어제 HTML로는 못 했던 것.

차례로 부르기 (순차 호출)

비유: 길 찾기 → 그 주소로 배달

도시 이름으로 위도·경도를 먼저 받고(1번 API) → 그 숫자를 넣어 날씨를 부른다(2번 API). 앞 응답이 다음 주소에 들어가요. 하나가 멈춰도 나머지는 보여야 해요.

오픈API와 금고 · 견본 · 문지기

비유: 코스트코 회원 카드를 금고에

실무 오픈API는 대부분 키가 필요해요. 키는 코드가 아니라 .env = 금고(안 올림), .env.example = 견본(이름만, 올림), .gitignore = 문지기("금고는 올리지 마", 올림).

키를 주소에 vs 헤더에

비유: 엽서 겉면 vs 봉투 안쪽

OpenWeather는 키를 주소 안(appid=키)에 받아요 = 엽서 겉면에 카드 번호. 주소를 출력하거나 공유하면 키가 보여요. ExchangeRate-API·카카오는 헤더(Authorization)로 = 봉투 안쪽. 그래도 둘 다 코드엔 안 쓰고 .env에서 꺼내요.

AI가 아는 API는 과거의 API일 수 있다

비유: 작년 지도로 길 찾기

네이버 검색 API는 2026년 7월 31일부터 개발자센터에서 새로 못 받아요. 카카오는 2025년 12월에 키 메뉴가 [플랫폼 키]로 바뀌었고요. Claude가 옛날 방식으로 짜면 AI 실수.

키가 새면 — 사고 대응 3단계

비유: 카드 잃어버리면 정지부터

① 키부터 교체 (새 키 만들고 옛 키 삭제) ② .env 갈아 끼우고 동작 확인 ③ 그다음 .gitignore 고치기. 커밋을 지워도 기록에 남아요.

  1. 가상환경 만들기 (conda) + requirements.txt (10:20)

    왜 가상환경? 프로젝트마다 따로 쓰는 파이썬 도구 상자예요. 요리마다 도마를 따로 쓰듯이 — 한 프로젝트에 깐 도구가 다른 프로젝트를 깨뜨리지 않고, 망가지면 상자만 지우고 다시 만들면 끝. 상자마다 파이썬 버전도 고를 수 있어요.

    왜 requirements.txt? 이 프로젝트에 필요한 도구 목록(장보기 목록)이에요. 상자는 내 컴퓨터에만 있고 GitHub에 안 올라가니까, 목록을 대신 올려요. 조원도, 새 노트북도, 내일 배울 서버(Vercel)도 pip install -r requirements.txt 한 줄로 똑같이 준비해요. (어제 .env.example처럼 — 실물은 내 컴퓨터, 설명서는 레포)

    없으면있으면
    가상환경모든 프로젝트가 파이썬 하나를 같이 씀 → 버전 충돌프로젝트마다 자기 상자, 안 부딪힘
    requirements.txt조원이 실행하면 ModuleNotFoundError → "뭘 깔아야 해?"목록 한 줄로 똑같이 설치

    VS Code 터미널에서 conda --version → 숫자가 나오면 통과. 없으면 Miniforge 설치 (자세한 건 자료의 01_파이썬_준비.md). git-practice/d7-python 폴더를 열고 차례로:

    ① 상자 만들기 (camp라는 이름, 파이썬 3.12)
    conda create -n camp python=3.12 -y
    ② 상자 열기 → 맨 앞에 (camp) 가 보여야 해요

    ④ 목록대로 설치 → 확인
